# Physics Experiment

A recorded comparison of a frozen learned model, probe-adapted model, and simple physics estimator for direct-contact pushing.

## Result

The tested adaptation improved predictions relative to the frozen model but worsened action selection in every seed. The simple estimator performed best. This is a preserved negative experiment, not a claim of successful learned adaptation or generalization.

The audited source, recorded demo, and reproducibility materials are being added to this clean public copy. No live web deployment is provided.
